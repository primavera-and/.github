# Primavera Andorrana – interní aplikace

Všechny interní aplikace firmy na jednom místě. Kód patří firmě, ne autorovi.

## Pravidla

1. **Kód patří firmě.** Každý repozitář je v této organizaci, ne na osobním účtu.
2. **Víme, co máme.** Každá aplikace je zapsaná v registru aplikací (správce, kde běží, data, přístupy).
3. **Každý repozitář má návod.** README podle šablony: instalace, spuštění, aktualizace, obnova ze zálohy.
4. **Žádné osobní účty a hesla v kódu.** Servisní účty, tajné údaje ve firemním správci hesel, `.env` se necommituje.
5. **Jedno místo pro provoz.** Aplikace běží na serverech Czechia s HTTPS a zálohami, ne na pracovních počítačích.
6. **Nové věci až po domluvě s IT.** Aplikace, domény i externí služby.
